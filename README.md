Velvet Vault Heist is a top-down stealth heist game: slip through three guarded museum rooms, lift the Star Sapphire, the Golden Idol and the Crown of Meridia, and reach the green exit door before the alarm hits 100%. Guards patrol with amber vision cones, cameras sweep red cones, and every tool — a smoke bomb, an EMP burst, sneaking — costs loot. Read the cones, plan a route, then run the getaway.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or arrow keys, hold Shift to sneak, click to throw a smoke bomb ($15 of loot), press 2 for an EMP burst ($25), R to retry a room, Enter to start.
